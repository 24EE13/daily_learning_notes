### 链表
由*元素域*和*指针域*构成，*元素域*和*指针域*构成的结构叫*结点*。

包含单链表、循环单链表、双向链表、静态链表。。。

#### 单链表
结点由一个一个元素域和指针域构成，结点之间通过指针链接，结点之间只有一个链接

**操作：**
0. 构建结构

```cpp
typedef struct Link{
	DataType* data;
	link* next;

} link;
```


1. 初始化

```cpp
void initLink(link **head) {
	(*head)->data = (DataType*)calloc(MAX, sizeof(DataType));//初始化数据域
	(*head)->next = NULL;//初始化指针域
}

```



2. 插入

```cpp
int insertLink(link* head, int index, DataType data) {
	Link *temp = head;
	while (index) {
		if (temp->next == NULL) {
			cout << "ERROR";
			return 0;
		}
		temp = temp->next;
		index--;
	}

	Link p;
	p.data= (DataType*)calloc(MAX, sizeof(DataType));
	p.next = temp->next;
	temp->next = &p;
	return 1;
}
```



3. 删除


5. 求元素个数 

```cpp
int LinkLength(link*head) {
	link* temp = head->next;//浮动的指针
	int count = 0;
	while (temp!=NULL) {
		count++;
		temp = temp->next;
	}
	return count;
}
```
6. 释放链表

```cpp
void deleteLink(link**head) {
	Link* temp = *head;
	Link* current = (*head)->next;
	*head = NULL;

	while (current == NULL) {
		free(temp);
		temp = current;
		current = current->next;
	}
```
