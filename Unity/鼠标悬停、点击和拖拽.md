

在 Unity 中实现鼠标拖拽 Image，最标准且高效的方法是使用 Unity 的事件系统接口。

核心原理是：让脚本实现 IDragHandler 接口，并在拖拽过程中通过 RectTransformUtility 工具类，将鼠标的屏幕坐标转换为 UI 画布（Canvas）的本地坐标，从而更新 Image 的位置。


IPointerEnterHandler	

鼠标/手指进入 UI 元素区域时触发	void OnPointerEnter(PointerEventData eventData)	指针（鼠标、触摸、手写笔等）首次进入物体的可点击区域时	高亮显示、改变颜色/大小、播放音效、显示提示框等悬停效果
IPointerExitHandler	

鼠标/手指离开 UI 元素区域时触发	void OnPointerExit(PointerEventData eventData)	指针离开物体可点击区域时	恢复悬停前的状态、隐藏提示、停止动画等
IPointerClickHandler	

在 UI 元素上完成点击时触发（按下并抬起）	void OnPointerClick(PointerEventData eventData)	指针在同一物体上按下并抬起，且期间未移出时	按钮功能、选择物品、打开界面、提交表单等单击交互
IDragHandler	

拖拽过程中每帧持续触发	void OnDrag(PointerEventData eventData)	在 BeginDrag 之后，EndDrag 之前，只要指针移动就会每帧调用	跟随拖拽移动物体、绘制拖拽轨迹、实时更新位置等
IBeginDragHandler	

开始拖拽时触发一次	void OnBeginDrag(PointerEventData eventData)	指针按下后移动超过一定阈值（默认 5 像素）时	初始化拖拽状态、创建拖拽克隆体、改变透明度、记录起始位置等
