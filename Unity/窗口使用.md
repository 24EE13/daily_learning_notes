
 **Hierarchy(层级)**:是一个场景的“目录”或“清单”。这个窗口中显示的“东西”，本质上是当前场景中所有的 *GameObject（游戏对象）*

 这里的游戏对象分为三类：
- 资源实例： 直接从资源文件生成的对象，比如你拖入场景的 3D 模型、导入的音频源等。
- 预制体实例 (Prefabs)： 这是 Unity 中非常强大的功能。它们是你预先配置好的自定义对象（比如一个完整的敌人角色、一辆车），在 Hierarchy 中它们通常以蓝色显示（默认设置下），代表它们是外部预制体资源的链接。
- 空对象 (Empty Objects)： 你可能看不到它们（因为它们没有形状），但它们在 Hierarchy 中用于组织其他对象，起到“文件夹”的作用。

组件（Component）：是赋予游戏对象（GameObject）功能、外观和行为的“功能单元”。包含脚本组件等。。。

## 预制件
它允许你将一个配置好的游戏对象（GameObject）及其所有组件和属性保存起来，然后在项目中任意创建它的副本（即“实例”）。

*⚠️ 一个重要的注意事项*   
*虽然脚本会保存在预制件中，但如果之后你删除了项目中的脚本文件（.cs 文件），预制件本身并不会报错，场景中的预制件实例也能继续存在。*

### 创建预制件

1. 在 Hierarchy（层级） 窗口中，创建并配置好你的游戏对象（例如，添加模型、材质、碰撞体、脚本等组件）。
2. 直接将这个配置好的游戏对象从 Hierarchy 窗口拖拽到 Project（项目） 窗口的任意文件夹中。

### 使用预制件
- 手动放置：将预制件从 Project 窗口拖拽到 Scene（场景） 或 Hierarchy 窗口中，即可创建它的一个新实例。你可以重复此操作来放置任意多个副本。
- 代码动态生成：在游戏运行时，通过脚本动态地创建预制件实例。这在生成子弹、敌人、特效等需要频繁变化的对象时非常有用。

代码动态生成示例：  
```cs
// 在脚本中声明一个公共的GameObject变量来接收预制件
public GameObject enemyPrefab;

void SpawnEnemy()
{
    // Instantiate函数会在指定位置和旋转角度创建一个新的实例
    Instantiate(enemyPrefab, new Vector3(0, 0, 0), Quaternion.identity);
}
```
