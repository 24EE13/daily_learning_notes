# 单例模式
单例模式（Singleton Pattern）是游戏开发中最常用的设计模式之一。它的核心目的非常简单：确保`一个类`在整个游戏中只有`一个实例`，并提供`一个全局访问点`。


这里讲的是MonoBehaviour 单例（Unity 专用）

- Awake 检查：在 Awake 中检查实例是否已存在，如果存在则销毁当前重复的对象。
- DontDestroyOnLoad：让对象在场景切换时不被销毁，保持全局唯一。

```cs
using UnityEngine;

public class AudioManager : MonoBehaviour//全局访问
{
    // 1. 静态实例
    public static AudioManager Instance { get; private set; }

    // 2.  Awake 中初始化
    private void Awake()
    {
        // 如果 Instance 已经有值，说明场景中已经有一个 AudioManager 了
        if (Instance != null && Instance != this)
        {
            // 销毁当前重复的物体，防止重复
            Destroy(gameObject);
            return;
        }

        // 赋值
        Instance = this;

        // 3. 跨场景不销毁
        DontDestroyOnLoad(gameObject);
    }

    // 业务方法
    public void PlayMusic()
    {
        Debug.Log("播放背景音乐...");
    }
}

// 调用方式：AudioManager.Instance.PlayMusic();
//解读：
/*
this 指的是“当前脚本组件实例本身”。（脚本本身）  
gameObject是Comment组件的一个属性，MonoBehaviour继承于Comment（脚本挂载的游戏对象）
销毁的那一行的作用是防止游戏对象在场景切换后没有被销毁，又因为切换后的场景本身有这个游戏对象，使得这个游戏对象被反复创建。
*/
```
