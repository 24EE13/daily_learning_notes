# 委托

## 委托是什么
简单来说是函数的容器，本质上是一种特殊的类。

## 委托的声明  

*写在namespace或class中*   
```cs
public delegate int Func(int a); //默认是public的访问类型,delegate关键字，其他的跟函数无异
```

## 委托的使用

调用委托本质上是调用函数，往委托里塞入函数不会复制函数本身。

```cs
//初始化（实例化）
Func f = new Func(函数1，函数2...);//方法1
Func f = 方法名;//方法2
Func f;//方法3
//添加函数（委托可以有多个函数）
f += 方法;
//删除函数
f-=方法;
//清空委托
f = null;
//调用委托
f.Invoke();
f();

//如果是含参函数。。。（锟斤拷）
```

委托可以作为函数参数，将函数传入另一个函数

```cs
//带有委托的函数
void func(Func f){
    print("12345");
}
void func2(){
    print("21");
}

//使用
int main(){
    Func f = func2;
    func(f);
    func(func2);//可以直接传函数名；
    
    return 0;
}
```

## unity系统自带委托

Action
默认无参无返回值。
Func
有返回值

```cs
Action<int,float> a;//两个参数
Func<int,float> b;//最后一个是返回值 

```

# 事件
事件是委托的包装，本质是一种特殊变量类型。



事件的声明
```cs
event Action 事件名;

```

事件的定义与使用和委托差不多，但不同的是，事件只能在类或者结构体中调用或赋值（不包括添加+=和删除-=）。
