# 协程

一种函数，能暂停执行，在指定时间点继续

## 协程使用

```cs
IEnumerator func(){//返回值类型一定是IEnumerator
    yield return null; //不能少了yield return
}

//yield return 是协程（Coroutine）的核心，它的主要作用是暂停协程的执行，并在满足特定条件后恢复执行。
//yield return 后面可以跟不同的指令，来实现不同的暂停效果。

```
- `yield return null;`   
最常见的用法，表示暂停到下一帧再继续执行。常用于将一个耗时任务拆分到多帧中执行，或者实现需要每帧更新逻辑的效果（如UI倒计时）。
- `yield return new WaitForSeconds(2f);`   
表示暂停指定的秒数（这里是2秒）后再继续。常用于实现技能冷却、延迟触发等。
注意：这个等待时间会受到 Time.timeScale（游戏时间缩放）的影响。如果你的游戏有暂停功能（Time.timeScale = 0），这个等待也会暂停。
- `yield return new WaitUntil(() => player.isReady);`   
表示等待直到某个条件满足。括号里是一个返回 bool 值的函数，Unity 会在每一帧检查这个条件，一旦为 true 就恢复协程。非常灵活，可以用来等待一个复杂的逻辑完成。
- `yield return StartCoroutine(AnotherCoroutine());`   
表示等待另一个协程执行完毕后再继续。这可以用来组织复杂的任务流程，比如先加载资源，再初始化场景。
- `yield return new WaitForEndOfFrame();`   
表示等待当前帧所有渲染工作完成后再执行。常用于在截图或应用后处理效果前，确保画面已经完全绘制好。
