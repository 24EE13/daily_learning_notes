## 函数重载

1. 整型（int long short）的重载规则*浮点型同理*
```cpp
// 1. 传入int类型实参
    int a = 10;
    printNum(a); // 精准匹配int版本

    // 2. 传入long类型实参
    long b = 20L; // 加L表示long字面量
    printNum(b); // 精准匹配long版本

    // 3. 传入字面量（默认int）
    printNum(30); // 匹配int版本（字面量30默认是int）

    // 4. 传入long字面量（加L）
    printNum(40L); // 匹配long版本

    // 5. 隐式转换场景（无歧义）
    short c = 5;
    printNum(c); // short会提升为int，匹配int版

    //如果传入的是float
    float d = 1.0;
    printNum(d);
    //或者
    printNum(1.0f);//要有后缀f，没有f是double类型
```

2. c++字符数组和字符串

```cpp
// 场景1：传入字符串字面量（默认是 const char[]，退化为 const char*）
    func("hello"); 

    // 场景2：传入 const char* 类型变量
    const char* c_str = "world";
    func(c_str); 

    // 场景3：传入 char* 类型变量（可隐式转换为 const char*）
    char* normal_str = const_cast<char*>("test"); // 仅测试用，实际不建议这么写
    func(normal_str); 

    // 场景4：传入 std::string 类型变量
    string cpp_str = "cpp string";
    func(cpp_str); 

    // 场景5：显式构造 string 对象
    func(string("explicit string")); 

    // 场景6：强制转换为 const char*（覆盖默认转换）
    func(static_cast<const char*>("cast const char*"));
```


3. 单个的const修饰和&引用不能构成重载

- `const`仅仅是用于修饰参数的可改性属性，本质上相同。 
```cpp
void func(int b);
void func(const int b);
```   

- `&`引用，请把它和类型本身视为同一特征标。
```cpp
void func(int b);
void func(int &b);
```

4. 组合使用的const修饰和&引用（包括*解引用）可以构成重载

下面来自豆包(*ai太好用了你知道吗*)
```cpp
#include <iostream>
using namespace std;

// 重载1：非const引用（可修改原变量）
void func(int& a) {
    a += 5;
}

// 重载2：const引用（只读，可绑定字面量/const变量）
void func(const int& a) {
    // a += 5; // 编译错误：const引用不可修改
}

// 重载3：非const指针（可修改指向的变量）
void func(int* a) {
    *a += 10;
}

// 重载4：const指针（只读，指向const变量）
void func(const int* a) {
    // *a += 10; // 编译错误：const指针指向值不可修改
}

int main() {
    int num1 = 10;
    const int num2 = 20;

    // 1. 非const变量 → 匹配int&版本
    func(num1);

    // 2. const变量 → 匹配const int&版本
    func(num2);

    // 3. 字面量 → 匹配const int&版本
    func(30);

    // 4. 非const变量地址 → 匹配int*版本
    func(&num1);

    // 5. const变量地址 → 匹配const int*版本
    func(&num2);

    return 0;
}
```

5. const与*的更多组合


ps:`nullptr`是空指针常量的意思  
*与`NULL`不同，`NULL`本质上是宏定义的0，`nullptr`是「空指针」*  

```cpp

// 重载1：（指向的内容不可改）+ （指针本身可改）
void func(const int* a) {
    cout << "[const int*] 版本: 指向内容不可改，指针本身可改" << endl;
    // *a = 100; // 错误
    a = nullptr; // 合法
}

// 重载2：(指向内容可改) + （指针本身不可改）
void func(int* const a) {
    cout << "[int* const] 版本: 指向内容可改，指针本身不可改" << endl;
    *a = 100; // 合法
    // a = nullptr; // 错误
}

// 重载3：(指向内容不可改) + （指针本身不可改）
void func(const int* const a) {
    cout << "[const int* const] 版本: 指向内容+指针本身都不可改" << endl;
    // *a = 100; // 错误
    // a = nullptr; // 错误
}

int main() {
    int num = 50;
    const int c_num = 60;

    // 1. 普通int* → 优先匹配int* const（精准匹配底层非const）
    int* p1 = &num;
    func(p1);

    // 2. const int* → 匹配const int*（精准匹配底层const）
    const int* p2 = &c_num;
    func(p2);

    // 3. const int* const → 匹配const int* const
    const int* const p3 = &c_num;
    func(p3);

    return 0;
}
```


## 函数模板 

是c++实现泛型的函数描述   
*泛型是 通用的、不挑具体数据类型的编程方式*（来自豆包）  
*函数描述意味着函数模板只是起到一个蓝图的作用*  

### 函数模板的实现
```cpp
template <typename T>
void myswap(T & a,T & b,int n){
	T c = a;
	a = b;
	b = c+n;
	
} 
```

也可以。。。

```cpp
//声明
template <typename T>
void myswap(T & a,T & b,int n);

//实现
template <typename T>
void myswap(T &a, T &b) {
    T c = a;
    a = b;
    b = c;
}
```
**注意这里的函数实现前面要写template之类的**

### 函数模板的原理

函数模板是泛型函数的蓝图，本身不生成可执行代码。
当程序调用该模板时，编译器会根据传入的类型，生成具体类型的函数，这个过程叫*隐式实例化*。


### 函数模板的显示具体化
显式具体化是 给模板的某个类型单独写特殊逻辑，用于结构体和数组写单独逻辑

例子：
```cpp
struct job{
	int salary;
	char name[10];
};
 
template <typename T>
void myswap(T &a, T &b) {//这里的函数模板可以是声明也可以直接写具体实现
    T c = a;
    a = b;
    b = c;
}

 template<>
 void swap1(job &a,job&b){
	job d ;
	d.salary = a.salary;
	a.salary = b.salary;
	b.salary = d.salary; 
	
}

```

或者。。。

```cpp
struct job{
	int salary;
	char name[10];
};
 
template <typename T>
void myswap(T &a, T &b) {//这里的函数模板可以是声明也可以直接写具体实现
    T c = a;
    a = b;
    b = c;
}

 template<>
 void swap1<job>(job &a,job&b){
	job d ;
	d.salary = a.salary;
	a.salary = b.salary;
	b.salary = d.salary; 
	
}

```


同样也可以先声明再实现

```cpp


// 声明
template<>
void swap1<float>(float &a, float &b);

 template<>
 void swap1(job &a,job&b){
	job d ;
	d.salary = a.salary;
	a.salary = b.salary;
	b.salary = d.salary; 
	
}
```

**ps：显式具体化 必须依附于一个已经存在的 函数模板！！！**
**它不能单独存在！**


### 函数模板的显式实例化

显式实例化是通过函数模板，提前生成某一特定类型的函数实例的方法。  

```cpp
template void swap1<float>(float&, float&);//写在函数模板的声明或者实现的后面
```

（锟斤拷。。。）
函数的版本匹配：  

在名称相同，参数数目相同的条件下

1. 完全匹配 > 提升转换 > 标准转换 > 用户自定义 

2.在匹配程度相同时： 非模板函数>显式具体化>模板函数
*显式实例化不参与优先级！*
